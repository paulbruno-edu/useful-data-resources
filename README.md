# Useful Data Resources

A searchable list of free data sources for quantitative research in education, published at
<https://data.paul-bruno.com>.

## How it's maintained

The list itself lives in a workbook outside this repository:

```
C:\GoogleDrive\UIUC\Projects\usefuldataresources\
├── useful_data_resources.xlsx   the master list (edit this)
├── export_site.py               writes this repository's data/ files from the workbook
└── check_links.py               rechecks every link and updates the workbook's Link status column
```

To update the site:

1. Edit the workbook, save, and close it in Excel.
2. Run `python export_site.py` in that folder.
3. In GitHub Desktop, commit the changed `data/` files here and push. GitHub Pages republishes within a few minutes.

## What's here

| Path | What it is |
|---|---|
| `index.html`, `assets/` | The page. When you change `app.js` or `style.css`, bump the `?v=` numbers in `index.html` so browsers fetch the new copy. |
| `data/` | Generated by `export_site.py`. Don't edit by hand. |
| `scripts/check_links.py` | Used by the monthly GitHub Action below. |
| `CNAME` | The custom domain for GitHub Pages. |

## Monthly link check

`.github/workflows/check-links.yml` checks every link in `data/resources.json` on the 3rd of each month.
If any link is broken (404 or 410), the run fails and GitHub emails you; the run's log lists the
broken links. Sites that block automated checks are reported but don't fail the run.
